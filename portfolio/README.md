# 🚀 Eng. Mohamed Dabah - 3D AI Interactive Portfolio

بورتفوليو ويب ثلاثي الأبعاد (3D Web Experience) مخصص للبشمهندس **محمد دباح (Eng. Mohamed Dabah)** مبني بلغة **Python** وأحدث تقنيات الويب والذكاء الاصطناعي.

---

## 🌟 المميزات الرئيسية
1. **محرك جرافيكس ثلاثي الأبعاد تفاعلي (Three.js WebGL):**
   - نواة ذكاء اصطناعي هولوجرامية (Holographic AI Quantum Core) تتفاعل لحظياً مع حركة الماوس واللمس على الموبايل.
   - فضاء ذرات كونية (Dynamic Particle Universe) وإضاءات نيون مستقبلية.
2. **كروت التواصل وأكواد الـ QR التلقائية:**
   - كود **QR** مخصص لكل منصة (واتساب، فيسبوك، لينكد إن، إنستغرام).
   - إمكانية مسح الكود بالكاميرا مباشرة أو الضغط على زر فتح الرابط السريع.
   - نافذة تكبير (Modal Viewer) لأكواد الـ QR.
3. **معرض المشاريع وأنظمة الذكاء الاصطناعي:**
   - عرض مشروع **AI Restaurant & WhatsApp Ordering Bot**.
   - كروت تفاعلية بنظام **3D Tilt & Specular Glare** تميل وتتحرك مع مؤشر الماوس.
   - فلاتر تصنيف سريعة (AI & WhatsApp, Multi-Agent, 3D Web, Computer Vision).
4. **تأثيرات صوتية مستقبلية (Synthesized Cyber SFX):**
   - أصوات تفاعلية ناعمة عند المرور والضغط مولّدة ذاتياً عبر Web Audio API بدون الحاجة لتحميل ملفات صوت خارجية.
5. **لوحة تواصل واستقبال الرسائل:**
   - نموذج إرسال رسائل سريع متصل بـ API بايثون.

## 📁 هيكلية وتقسيم الملفات (Clean Architecture)
```text
portfolio/
├── app/
│   ├── __init__.py
│   ├── config.py           # ⚙️ ملف البيانات: اسمك، أرقامك، روابطك، والمشاريع
│   ├── qr_generator.py     # 📱 مولد أكواد الـ QR التلقائي بألوان كل منصة
│   ├── routes.py           # 🌐 مسارات FastAPI (الصفحة الرئيسية والـ API)
│   ├── main.py             # 🚀 سيرفر FastAPI وإعدادات الملفات الثابتة
│   ├── static/
│   │   ├── css/
│   │   │   └── style.css   # 🎨 تصميم الدارك مود النيون، Glassmorphism والتجاوب
│   │   ├── js/
│   │   │   ├── three_core.js   # 🌌 كود الـ 3D التفاعلي (Three.js Engine)
│   │   │   └── interactions.js # ⚡ مؤثرات الميلان 3D Tilt والأصوات والـ Modals
│   │   └── images/
│   │       ├── profile.jpg     # 📸 صورتك الشخصية
│   │       └── qr/             # 🔲 أكواد الـ QR المولدة تلقائياً
│   └── templates/
│       ├── base.html       # الهيكل العام وروابط المكتبات
│       └── index.html      # محتوى الواجهة والتفاصيل
├── requirements.txt        # المكتبات المطلوبة
└── run.py                  # ملف التشغيل الرئيسي
```

## 🚀 كيفية التشغيل (How to Run)

### الطريقة الأولى (بضغطة زر واحدة):
اضغط مرتين (Double Click) على الملف:
```cmd
start_portfolio.bat
```

### الطريقة الثانية (عبر موجه الأوامر Terminal):
```bash
.\venv\Scripts\python.exe portfolio\run.py
```
سيبدأ السيرفر فوراً على: **`http://127.0.0.1:8500`** وسيفتح المتصفح تلقائياً.
